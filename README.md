Working repository for offensive lab research, custom tooling, and detection
telemetry. Everything here is built, tested, and verified in isolated
enterprise lab environments.

### Directory

```
├── attack-chains/       # end-to-end AD & segmented network compromise paths, ATT&CK-mapped
├── writeups/            # HTB / THM / custom AD lab write-ups
├── infrastructure/      # C2 and redirector build notes (sanitized)
├── detections/          # Sigma rules, Sysmon configs, telemetry per chain
├── templates/           # write-up and report templates
├── tooling/             # custom scripts, loaders, enumeration utilities
└── reports/             # redacted lab engagement reports
```

### Active Work

- `writeups/custom-ad-lab/` — AS-REQ/TGS-REQ ticket lifecycle, PAC validation, delegation edge cases
- `tooling/` — Sliver C2 infrastructure: beacon configs, HTTP redirectors, deployment templates
- `reports/` — CRTS v2 lab replication write-ups

### Rules of Engagement

- All work conducted in isolated lab environments under my control
- No live infrastructure, no third-party systems, no unpatched disclosures
- Exam and client material withheld per certification / NDA terms
- Every attack chain ships with its detection counterpart — offense without telemetry is half a write-up
